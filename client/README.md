# Thalam Jewels

Elegance in every sparkle — a luxury ecommerce storefront built with React, Vite, and Tailwind CSS.

## Stack

- **React 19** + **Vite 8**
- **Tailwind CSS 4** (via `@tailwindcss/vite`)
- **Framer Motion** for scroll and entrance animations
- **React Router** for multi-page navigation
- **Lucide React** for icons

## Pages

| Route | Description |
|-------|-------------|
| `/` | Animated landing page with hero, categories, featured products, testimonials |
| `/shop` | Full product catalog with category filters |
| `/about` | Brand story, milestones, and values |
| `/contact` | Contact form and boutique information |

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
npm run preview
```
